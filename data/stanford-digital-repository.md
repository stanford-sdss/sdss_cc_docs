# Stanford Digital Repository

The [Stanford Digital Repository (SDR)](https://sdr.stanford.edu) is a storage platform managed by Stanford Libraries that holds data, code, and other information related to published works. SDR supports persistent URLs and DOIs, making it ideal for published research outputs.

## Depositing Data

Depositing data is very easy!  Stanford Libraries has compiled [a list of tutorials on SDR at this page](https://sdr.library.stanford.edu/tutorial-videos) which explain many different facets of depositing data.
