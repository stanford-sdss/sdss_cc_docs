## Interactive Session Guidelines
1. No longer than 8 hours of time
2. Limit yourself to 2 GPUS and 32 CPUs

## GPU Guidelines in Batch Jobs
1. Please use the 40GB GPUs when possible
2. Limit yourself to 8 concurrent GPUs
3. Respect the memory per GPU limit

## CPU Guidelines in Batch Jobs
1. Limit yourself to 1000 concurrent CPUs
