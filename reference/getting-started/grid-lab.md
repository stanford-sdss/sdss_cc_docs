# G.R.I.D. Lab

## Overview
The _Geo-Research, Imaging, & Design_ computer lab (*_GRID Lab_*), strictly speaking, is not a SDSS-CC resource, it can be a useful resource for workflows that require Windows (only) based software and other GUI interfaces. GRID Lab consists of onsite resources, including computers, scanners, and wide-format printers, and remotely accessible Virtual Machines (VMs). For more information, see the gridlab docs:

[https://gridlab.stanford.edu](https://gridlab.stanford.edu "GRID Lab docs") 

## Remote connectioons
Remote connections to _GRID Lab_ require the Stanford VPN and an RDP client:
- Connect to Stanford VPN.
  - Windows setup instructions here: [https://uit.stanford.edu/service/vpn/win_anyconnect](https://uit.stanford.edu/service/vpn/win_anyconnect "Windows VPN setup")
  
  - Mac setup instructions here: [https://uit.stanford.edu/service/vpn/mac_builtin](https://uit.stanford.edu/service/vpn/mac_builtin "Mac VPN setup")

- Open the Microsoft Remote Desktop application. 
  If you are on a Mac, first go to the Apple App Store and download the latest RDP application from Microsoft, it has an orange icon.

- Fill in the following information for the connection address (might be called `PC Name`). 

  `se3-grid-lab.stanford.edu`
- Username and password prompt. 

   `Username: win\SUNnetID` 
   `Password: “Your regular password”`

- Open the application you want to use in the RDP virtual desktop.
